# One prompt to a general coding agent (baseline)

The same county (Panola), the same two inputs, one prompt (`prompt.txt`), no follow-up. `findings.json` and `summary.md`
are that agent's output, kept exactly as it wrote them; `run.json` says how it was run.

Read this before quoting anything from it: the statements in `summary.md` are that agent's own readings of the scan.
Nobody has checked them, and nothing here is a statement about a county's certified results. Where its output and
Crossfoot's disagree, the printed totals on the scan decide, and the comparison is written up next to this folder once
it has been scored.
