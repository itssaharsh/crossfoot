The loop (ARCHITECTURE.md has the action list; this is how to read it):
- Work list: the failing sums, grouped by block. An item is one failing sum with the cells on it and the checks that cross it (`checks.locate`).
- For each item `claude-haiku` is shown the item as text (the block, the failing sums with their terms and printed totals, what has been tried on it) and answers with one JSON action: `reread` (a target, a dpi of 300 or 400, a model), `cannot_verify` (a reason) or `done`. One decision may list several re-reads for the same block. Code carries the action out, checks the rules, writes an event, and answers with the checks' new result.
- Re-read targets: a column slice (the three cells of one precinct in one block with the small total under them), a single cell, a row's printed total, a block's grand total. Cut the crop from the 300 or 400 dpi page with padding, enlarge small crops so digits are at least 40 px tall, and say in the prompt what the crop holds. The cell boxes in the ledger come from the column lines (fixed in T02a); printed totals have no boxes yet, so work their boxes out from the block's edges and rows.
- A printed total can be the misread value. When a column sum fails and the three rows it crosses all pass, look at the small total first. When a row sum fails and every column on it passes, look at the row's printed total first.
- A re-read that returns a different value: code keeps the value under which more of that cell's sums hold, and the event records both readings. A model never sets a status; statuses follow from the checks.
- Every action is a neatlogs TOOL span (`reread_cell`, `reread_column`, `check_sums`, ...) tagged with run, county, page, block and cell; the loop over a county is an AGENT span; decisions are LLM spans through the wrapped client.
- Events (`ledger.event`) are what the results page replays later: write one for each decision, re-read (target, old value, new value, model, dpi), check result, status change and stop, in order, with enough in the payload to draw it (page, block, row kind, column, box).
