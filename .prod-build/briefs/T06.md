Acceptance (REQUIRED):
- WHEN `crossfoot site build --latest` runs THE SYSTEM SHALL write `site/data/index.json` (runs, counties, headline numbers, all from run files), one JSON per county (pages with image path and pixel size, blocks, cells with pixel boxes where known, checks, findings, events), page images for pages that carry findings (at most 1600 px wide, PNG or WebP) and the crops
- WHEN the page opens THE SYSTEM SHALL show a finished run with the first settled finding selected and drawn, at 1440x900, with no input (AC-6, local)
- WHEN a finding is selected (pointer or keyboard) THE SYSTEM SHALL turn the sheet so the cell is centred, draw the row line then the column line, ring the cell, print the tape, and update the two values and the status line
- WHEN a cell's pixel box is not known THE SYSTEM SHALL show the finding's crop flat in the stage instead of the sheet, with the same tape and values
- IF a data file fails to load THEN THE SYSTEM SHALL show which file and keep the rest of the page working
- Every number on the page is read from `site/data/`. A number the run did not record is left out, never shown as 0. No invented text, names or figures.

Constraints (from UI-SPEC.md, verbatim where it matters):
- Plain HTML, CSS and JavaScript modules. No framework, no bundler, no npm dependency. Files: `site/index.html`, `site/styles.css`, `site/app.js` (split into a few modules if it helps), `site/favicon.svg`.
- Tokens exactly as in UI-SPEC.md section 14; fonts Public Sans and Courier Prime from Google Fonts with system fallbacks. Check each text and background pair for 4.5:1 and fix the muted ink first if one fails.
- The sheet: an `<img>` of the scan page inside a container with `perspective: 1800px`; the sheet is transformed `rotateX(34deg) rotateZ(-3deg)`; marks are an SVG overlay in the image's pixel coordinates so they tilt with it. Selection changes the transform so the cell sits at the optical centre. `Lay flat` removes the rotation. Under `prefers-reduced-motion: reduce` and under 900px wide the sheet starts flat.
- Colours of marks: `--data-holds` for a sum that holds, `--data-fails` for one that fails. No gradients, glows, glass, confetti or sound.
- Copy exactly from UI-SPEC.md section 9. Row labels come from the data as printed on the scan; add no comment about any candidate, party or official.
- The stage has `role="img"` with a label that describes the selected finding in words; the findings list is the keyboard path (one tab stop, arrow keys move, Enter selects).
- This task is the golden path only: the ideal state on desktop. Replay, the other states, small screens and the checks come in T07, so structure the code so they can be added without a rewrite.
